## Artifact policy

A model artifact may be attached to a Release only if it is (a) **generated by this project**, or (b) **properly authorised for redistribution**. Neither holds today:

- No model has been trained by this project, so there is nothing of type (a) and **no model checksum exists for this project**. No empty archive and no invented checksum is published.
- The two NanoParse archives are not authorised for redistribution (no licence file, no written permission), so they are not attached (b).
